## 项目简介

Amadeus 是一个围绕**实时对话、桌面感知、角色化表达和工具执行**构建的桌面 AI Agent 实验项目。

它不只是一个聊天窗口。项目希望把语音、多模态理解、角色渲染和实际任务执行连接为连续的交互过程：能够听见用户、观察桌面、实时回应，以具有表现力的角色形态呈现，并在需要时调用外部工具完成工作。

## 项目方向

Amadeus 目前围绕以下能力持续开发：

- 实时语音识别、流式对话与低延迟语音合成
- 截图、摄像头等多模态上下文输入
- 多种云端及本地大语言模型后端
- 角色动画、口型同步和情绪表达
- 桌面交互与外部工具任务委派
- Coding Agent、工作流管理与任务进度呈现
- 本地化运行和个人知识增强

其中部分能力仍处于实验或重构阶段，最终公开版本的功能范围以首次源码发布说明为准。
