范围：PR #116（`b90a5a1` → `d6c93de`）与后续本地浮层修复 `833ea8a`。本次不调整 VN 语义策略。

## 底边多出一层

恢复旧卡片时同时移植了一个向下偏移的圆角底板：底板延伸到 `height - 2`，主边框只到 `height - 6`。约 4 个逻辑像素的露出形成第二层底边。本次删除该底板，保留主体圆角及内侧细边。

此前验收截图通过游戏截图路径输出 RGB，透明区域会呈黑色。窗口截图工具增加仅供显式调用的 `preserve_alpha` 选项，保留 WGC 的透明度并解除颜色预乘。游戏截图调用仍默认 RGB。新的实际窗口 PNG 保持 RGBA，底部 8 个物理像素完全透明；不通过桌面截图或裁剪隐藏问题。

本次验证：截图及浮层相关 19 项测试通过，原生窗口探针 15 项通过。图像位于本地 `output/diagnostics/vn-overlay-no-shadow/`，未发布可选角色素材。

## 本所七大不可思议：保留内容与证据边界

- 内置 PARANORMASIGHT 配置仍选择 `mystery`，加载对应剧本，保留日语输出、20–50 句前瞻窗口和前瞻模型调用预算。实际可用通道仍取决于模型配置、完整剧本和运行期对齐。
- `vn_player/prompts.py` 中即时回应、前瞻、推理归档、剧情摘要、回顾五个 Mystery prompt 的函数 AST 与 `b90a5a1` 一致（对照时只排除新增 Base 分支）。这些 system messages 随对应模型调用发送，不是只在开局调用一次的独立初始化模型。
- 原 Evidence、Mystery、Affect、Choice 四组关键词集合与 `b90a5a1` 一致，已从 runtime 搬至 `mystery_policy.py`。其中包含本所专属术语；普通 VN 不使用这些规则，但它们目前仍在通用 Mystery 策略模块中。
- 本次重新对照真正的 PR 前基线 `b90a5a1`：80 条历史实录的规则反应、摘要、回顾均无差异。报告：`output/diagnostics/vn-pre-pr116-mystery-replay/comparison.json`；提示词/词表 AST 对照：同目录 `source-contracts.json`。
- 该回放关闭模型调用，并为比较旧链路节奏过滤重复 script_id；不证明线上模型措辞、全分支体验或真人 ASR/TTS 完全等价。真实剧情重复/分支回访的保留是另行测试的有意修正。
- 用户已决定的接入与产品改动仍有效，例如 Agent 只走 WebSocket、独立 VN 视觉、后台摘要/回顾、初版移除独立静音。不能把这次改版描述为所有行为逐项不变。

后续语义设计建议：保留通用陪玩约束与各通道职责，将游戏背景/术语和本所专属规则明确归属到游戏配置。开局说明可以提供已知背景和玩法，不携带未来剧情答案，也不代替持续更新的剧情记忆。该建议尚未在本次外观修复中实施。
