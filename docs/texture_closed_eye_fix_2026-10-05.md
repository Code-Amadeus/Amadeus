# 闭眼片段缺帧：诊断与修复

第四次进入 `idle_closed_eye` 的连续缺帧已在固定路线中修复。问题位于纹理
HTTP 读取路径：在 FrameStore 和本地 BC7 派生缓存之外，浏览器还缓存了响应。
保留这层响应缓存的两组记录都出现超过 500 ms 预取余量的读取停顿；纹理请求
改用 `cache: "no-store"` 后，目标片段缺帧归零。

这是缓存与传输的集成问题。没有调整 2 GiB 预算、预取窗口、并发数、淘汰顺序、
采样计划、动画时钟或素材。BC7 磁盘缓存继续使用，修复请求和原始 UASTC 请求
沿用相同的响应缓存策略。其他静态资源仍可使用 HTTP 校验。

## 定位过程

1. 60 秒直接冷进入闭眼片段没有复现。另一个仅预置前 138 个浏览器缓存响应的
   短实验也未复现，因此没有保留该实验参数，不能把简单冷进入测试当作原故障验收。
2. 重跑 345 秒固定路线，开启已有的逐次 `fetch/load/upload` 和 Resource Timing
   记录，正式自动 BC7 实现复现了第四次闭眼的 43 次缺帧（逻辑帧 141–183）。
   典型慢帧总加载 794 ms，其中 HTTP 读取约 792 ms，后续解码约 2 ms。
   没有 GL 错误、源加载失败、BC7 校验错误或目标阶段的新转码。
3. 小响应与大响应交替提示需要排查连接传输。仅开启 `TCP_NODELAY` 后仍有
   38 次缺帧，最长加载 818.2 ms；该改动和对应临时测试已经撤回。
4. 保持原服务器和渲染调度，只有压缩纹理的 `fetch` 指定 `cache: "no-store"`。
   同一目标路线通过。读取仍由本地资源服务器从 BC7 派生文件或原始文件提供，
   没有禁用 BC7 缓存，也没有改成所有纹理常驻。

观察支持绕过重复的浏览器响应缓存；没有进一步隔离 Chromium 内部的磁盘淘汰、
校验或缓存事务锁各自的影响，因此不把某个内部机制或上游缺陷写成已证实原因。

## 同机对照

RTX 4070 Laptop 8 GiB，standard 60 FPS，采样开启，2 GiB，固定片段路线，每组
345 秒，串行各一次；新建浏览器 profile，共用逐步填充的隔离 BC7 缓存。
不运行 ASR/TTS，不清空系统文件缓存。这是故障诊断，不是新的整机 CPU/能耗基准。

| 指标 | 修复前 | TCP_NODELAY，未采用 | 绕过浏览器响应缓存 |
| --- | ---: | ---: | ---: |
| 第四次闭眼缺帧尝试 | 43 | 38 | **0** |
| 该次闭眼最慢 HTTP 读取 | 791.5 ms | 815.5 ms | **24.5 ms** |
| 该次闭眼最慢完整加载 | 794.0 ms | 818.2 ms | **28.6 ms** |
| 第四轮 idle 缺帧尝试 | 24 | 0 | **0** |
| 全程缺帧尝试 | 84 | 70 | **16** |
| 目标阶段新增转码 / 缓存写入 | 0 / 0 | 0 / 0 | 0 / 0 |
| 源加载失败 / GL 错误 | 0 / 0 | 0 / 0 | 0 / 0 |
| Store 驻留超过 2 GiB | 否 | 否 | 否 |

修复后 16 次缺帧为启动 idle 15 次、首次 thinking 转场 1 次；后续三轮没有缺帧。
两组候选的全程均为 12,903 次 BC7 命中、零转码；初始基线早期还在补齐缓存，
但三个目标闭眼阶段都没有新增缓存 miss 或写入。不能把全程 CPU 差异当作纯粹
HTTP 策略收益，也不承诺所有启动状态、宿主和连续数小时运行都零缺帧。

三组均完整结束，无事件丢失和运行中源码变化。记录包含源码哈希；前后部分
探针/服务器文件恢复临时实验后因工作区换行转换而有不同字节哈希，规范化 Git
diff 已确认这些文件没有保留改动。最终生产差异只在
`frame_texture_backend.js` 的请求策略。

## 验证与代价

- 68 项 Node backend/store/lifecycle 测试通过。新增断言覆盖 BC7 命中、原始
  UASTC 读取和损坏缓存修复，保证三条路径均绕过浏览器响应缓存；取消、资源所有权、
  上传和上下文恢复的既有契约仍通过。
- 纹理重取现在每次通过本地 HTTP 传输响应体，不复用浏览器缓存中的响应体；
  仍从已经生成的 BC7 文件解压，避免反复 UASTC 转码。这可能增加本地传输量，
  不能把本轮结果描述成减少所有 I/O 或已经重新验证先前 CPU 降幅。
- 不同平台的可见宿主、模型竞争及多小时验收仍保留为 draft 后续范围。
- [精简证据](evidence/texture-closed-eye-2026-10-05.json) 保留采用方案、基线、
  失败的 TCP 候选与目标阶段明细。完整诊断和未采用补丁留在本机实验目录
  `pr155-closed-eye-2026-10-05`。
