# VN Player：产品修订与验收（2026-09-25）

本轮落实产品自审中的显示契约、启动生命周期、配置引导、会话控制与浮层交付问题。深层的跨游戏语义设计继续单列讨论。代码在 `codex/vn-text-source-adapters`；本轮没有修改 Agent 或 Luna 的上游代码。

## 已落实

- 游戏启动、文本来源、VN 会话控制分别归属 launcher、source adapter 和 runtime/handler。Agent 与 Luna 档案都能使用程序或 Steam 启动，公共 `vn.line` 仍只要求非空文本，不要求说话人、剧本 ID 或特定 hook 线程。
- 真实回复从 `reaction.speak` 读取；沉默不再伪装成陪伴发言，摘要正确读取 `scene_summary`。玩家消息由运行期在回答前发布。
- 最近 200 条可见活动由运行期保存；页面重载恢复并按事件身份合并，诊断流不挤占剧情流。这是同一运行期内的页面恢复，不等于重启程序或游戏读档后的语义恢复。
- 状态展示区分启动、等待首次文本、正常跟读、取文中断、进程退出和模型不可用。没有新台词不会单独被判为失败；等待 Steam 时可取消，同一 WebSocket 上的取消不会被启动请求堵住。
- 首次安装不再显示未安装的开发者游戏档案。设置提供 Agent 官方下载和脚本仓库入口；选择游戏 exe 后可从匹配的 Steam manifest 填写 app ID，脚本文件选择器从已配置 Agent 的脚本目录开始。
- “本次游玩”提供评论频率、暂停主动评论、后续回复朗读、ASR、VN 提问截图、浮层显隐。临时调整不修改档案；能力随游戏类型选择，只展示，不提供任意组合开关。
- 暂停主动评论仍记录剧情、运行总结并回答问题；模型生成中的主动评论也会在返回后检查暂停状态。朗读开关只影响后续语音提交；当前声音使用独立的“停止语音播报”。
- VN 视觉继续独立于通用视觉，只读取绑定游戏窗口；通用开关管非 VN 场景。
- 实机复核发现 Pillow 的 HWND 抓图仍会混入遮挡窗口，已替换为 Windows Graphics Capture。原生库在第二款游戏上曾触发访问冲突，因此每次截图放入短生命周期的隐藏子进程；超时清理其进程树，错误明确返回，不降级为桌面截图。没有因此修改 hook 接口。
- 浮层默认开启，窗口源码已移入仓库内；不再加载外部旧 helper 或裁剪脚本。共享原有 Companion Lite 动画资源。未安装可选头像包时显示简洁头像与字幕；隐藏后不会被新回应重新弹出，长字幕会扩展窗口高度。

### 主宿主中的窗口视觉复验

完整 `server.app` 宿主中依次验证 Kemono 与 PARANORMASIGHT，各运行一次预览截图和一次由正常提问 handler 触发的新截图。默认浮层开启，两款截图均只含游戏窗口，模型识别出实际菜单。使用同一个宿主完成两款游戏验证，截图子进程结束后宿主继续可用。独立遮挡实验用两扇重叠的真实窗口验证：捕获的仍是被遮挡目标的颜色。

- `output/diagnostics/vn-host-vision-kemono-isolated-20260925/report.json`
- `output/diagnostics/vn-host-vision-pns-isolated-20260925/report.json`
- `output/diagnostics/vn-window-capture/report.json`

报告保留 `needs_visual_review` 原始状态；本次逐一查看报告引用的截图，确认没有浮层/其他应用，回答中的菜单与截图相符。Kemono 复验复用当时已运行的游戏，结束后保留该进程；PARANORMASIGHT 由测试启动并关闭。这不替代上面的 Steam 冷启动记录。

初次主宿主音频报告 `vn-host-io-pns-20260925` 的自动 `passed` 判定被复核撤销：CUDA 推理异常产生静音块，播放开始/结束事件不足以证明真实语音成功；旧视觉也混入了遮挡窗口。探针已改为检查新生成音频非静音并保留截图供人工复核。用户要求暂不追查可能与 eGPU 有关的推理故障，后续视觉验证在仅本次测试进程设置 `TTS_BACKEND=disabled`，未修改保存的音频设置。

## 本轮不能据此宣称通过的部分

- Luna 在上述具体游戏中的正文提取质量。Luna 的公共接入与运行期边界已测，逐游戏的取文选择仍需实机确认。
- 主宿主中的真实麦克风识别仍需用户说话配合；尚未通过。TTS 音频播放遇到 CUDA 推理异常，按用户要求暂不排查；播放事件不作为真实发声的通过证据。
- 长时间剧情理解、读档、分支回访及剧透约束的语义质量。三行与一次问答属于接入和呈现冒烟验收，不代表完整游戏通过。

因此，本轮结果是可复用接入与会话控制的一次经过验证的迭代，尚不宣称完整商业化发布验收完成。
