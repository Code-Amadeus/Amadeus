# VN 分支审计复核与修复

对照 Claude 的 `output/reviews/vn-branch-audit-2026-09-25/AUDIT.md` 和审计基线 `c11e1b3` 逐项检查。原审计保留，本文记录 Codex 的判断和实际修改。

## 复核判断

- A1、A2 可复现，属于运行时调度和 WebSocket 调度缺陷。
- A3 成立，值得在合入前修复：前端超时会让仍在正常等待 Steam 的启动显示失败。后端的 60 秒仅是等待游戏进程的预算，客户端还需覆盖后续窗口和取文初始化。
- A4、A5 以及 A6 的运行期清理成立。删除旧迁移前确认本机保存档案没有旧 `capabilities` 字段。
- D1 应限定为 PARANORMASIGHT 关键词及兜底规则的适配范围，不据此否定已验证的推理结构。
- D2 的串行积压结论成立，但“每句一次模型”需要限定：启用且未暂停时每句进入即时模型流程；模型要求补取上下文时还可能有第二次调用。关闭通道或暂停主动评论时不成立。
- A1 列出的两处现有语义测试明确使用规则路径；保留其同步断言。模型后台路径另加事件、存储与会话隔离测试。

## 已落实

| 项目 | 修改与边界 |
| --- | --- |
| A1 | 模型摘要和回顾各用一个后台串行任务，按触发时快照排队。保留普通 VN 的 12 句摘要和从第 40 句起每 40 句回顾的节奏。停止/替换会话取消任务及队列；即使模型吞掉取消，迟到结果也不能写入原会话或新会话。无效的新启动请求不会取消当前任务。即时评论的逐句顺序不变。 |
| A1 调用方 | 模型路径不再把结果塞回该句的同步返回值；事件和存储为结果入口。离线长跑评估在每个块结束时等待后台上下文更新，再读取摘要和回顾。规则路径仍同步。 |
| A2 | 三个 VN 控制方法进入当前连接的 TaskGroup；它们等待 ASR、启动或退出时不阻塞接收中断。输入锁、启动取消和连接关闭时的收尾保持原合同。 |
| A3 | 仅 `vn.launch.start` 的客户端预算改为 75 秒，其他请求保持 30 秒；Steam 等待仍为 60 秒，仍可取消。 |
| A4 | 删除分支内未发布格式的迁移；保存档案仍拒绝单独的能力开关。 |
| A5 | 删除空扫描线循环及只测死路径的测试；保留窗口注入测试入口；基类初始化句子身份；HTTP 入口拒绝非整数时长。补充复现并处理了超长 EMO 时长标签的数值溢出，不在轮询循环添加吞错兜底。 |
| A6 | Agent 进程检查改用 psutil；退出状态不再出现 running + 空 PID；Luna URL 在保存和启动使用同一校验；逐句推送复用档案快照，显式刷新和保存仍读磁盘/检查安装路径，损坏档案仍报错。 |
| A6 字段 | 删除未被读取的重复 profile 字段；能力以 `capabilities.lookahead` 为准。模型状态明确为 `llm.lookahead_llm_enabled`。旧输入别名仍有回放工具和外部 live runner 使用，因此保留。 |

后台排队只适用于摘要/回顾模型任务；没有修改评论过期、丢弃或采样策略，没有新增文本协议，也没有改变 Agent/Luna 与 VN 核心的边界。

`b4e8355` 与 `b90a5a1` 的 stable patch-id 相同，确认是重复补丁。本次未重写分支历史、推送或合并；合入时再整理该重复提交。

## 验证

- 原 A1、A2 探针：2 项通过。A1 的第 13、14 句延迟从约 1.22、1.23 秒降为 0.19、0.20 秒；模型摘要依然生成。这是固定 1 秒模型替身下的本地测量，不是线上性能承诺。
- VN 与 WebSocket 回归：133 项通过。
- 前端：147 项通过，TypeScript 与生产构建通过；构建仍有已有的 bundle 大小提示。
- PARANORMASIGHT 的 80 条实录对照 `c11e1b3`：逐句结果无差异，规则摘要、回顾完全一致。报告：`output/diagnostics/vn-audit-20260925/mystery-replay/comparison.json`。
- 原生浮层：实际 Tk、头像资源、播放事件、显隐及资源清理探针通过。报告：`output/diagnostics/vn-audit-20260925/overlay/result.json`。
- 新增双来源测试：Agent/Luna 实际本地 WebSocket 各传入 81 句，阻塞摘要和回顾模型时仍继续按顺序处理全部台词和即时反应；每个通道保持串行，触发快照不包含后到台词。

本轮没有重跑真实游戏注入、线上模型、真人麦克风和真实 TTS。它们沿用先前报告及其明确的未验收边界。

## 后续产品决定

审计修复本身没有修改 D1–D6 的默认值或玩家操作方式。随后用户决定从初版移除独立静音功能：对应的会话开关、档案字段及运行期开关已删除，保留中断当前播报、暂停主动评论和 ASR。D3 的文字展示、排队及错误反馈仍需独立设计；直接覆盖浮层字幕会干扰正在播放的句子，本轮未这样处理。

D5 随后由用户确认在草稿 PR 前处理：初版 Agent 仅使用 WebSocket，连接失败或断开时显示状态并重连；自动回退和显式剪贴板模式都从该适配器移除。旧模式请求明确报错，统一文本入口与 Luna 适配边界保持独立。回归覆盖首次拒连、断线、恢复及真实重复台词，并确认整个过程中没有访问系统剪贴板。
