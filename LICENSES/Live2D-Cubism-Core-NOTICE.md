# Live2D Cubism Core exclusion record

The private development checkout previously carried
`render/web/vendor/live2dcubismcore.min.js` as an optional compatibility
runtime. Its own header identifies it as Live2D Cubism Core, copyright Live2D
Inc., and proprietary "Redistributable Code" governed by the Live2D
proprietary software license agreement.

That runtime is not open-source code and is excluded from the Amadeus public
source archive. This notice records the exclusion decision; it does not copy,
relicense, or grant redistribution rights to Cubism Core.
